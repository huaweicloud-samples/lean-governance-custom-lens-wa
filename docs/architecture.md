# 架构说明

`lean-governance-custom-lens-wa` 提供一套**华为云架构评估检查单库**：把 Well-Architected 自定义 lens 检查项转译为华为云语境可执行的检讨清单，覆盖数据库 / 容器 / 对象存储 / 消息 / 无服务器 / 身份 / 数据分析 / AI 等 20+ 服务域。

## 使用形态

```
                            ┌────────────┐
                            │ 架构评审者 │
                            └──────┬─────┘
                                   │ 选域
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│       Well-Architected 检查单库（22 个架构域 / 554 检查项）        │
│             每题含：说明 + 期望回答（参考） + 改进计划             │
└──────┬─────────────┬─────────────┬─────────────┬─────────────┬─────┘


 ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
 │ DATABASE │  │CONTAINER │  │ STORAGE  │  │SERVERLESS│  │ANALYTICS │
 │ GeminiDB │  │   CCE    │  │   OBS    │  │   APIG   │  │   MRS    │
 │  DocDB   │  │   CCI    │  │ Iceberg  │  │   FGS    │  │   DLI    │
 └─────┬────┘  └─────┬────┘  └─────┬────┘  └─────┬────┘  └─────┬────┘
       │             │             │             │             │
       └─────────────┴─────────────┬─────────────┴─────────────┘
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                三档自评（良好 / 部分符合 / 不符合）                │
│               产出行动项：责任域 + 优先级 + 目标日期               │
└────────────────────────────────────────────────────────────────────┘
```

## 核心组件

| 目录 | 说明 |
|---|---|
| `src/checklists/*.md` | 22 个检查单（按架构域组织，共 554 检查项） |
| `docs/` | 架构说明 + 使用指导 |
| `docs/lens-notes/` | 22 份领域检查单说明 + 1 份自定义检查单创建指南 |
| `docs/service-mapping.md` | 架构域与华为云服务映射表 |
| `README.md` | 16 章使用文档（含服务映射总表） |

## 设计说明

- 每个检查单按 Well-Architected 支柱（安全/可靠性/性能/资源开销/运维/可持续）组织题目
- 每题含「说明 / 期望回答（参考）/ 改进计划」，可三档自评（良好/部分符合/不符合）
- 服务名已映射到华为云对应项（GeminiDB→GeminiDB 等），题目语义保留
