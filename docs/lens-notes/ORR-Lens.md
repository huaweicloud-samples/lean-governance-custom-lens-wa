# 运维就绪度 检查单说明

> 本文件说明本仓 `ORR-Lens.md` 的定位、覆盖范围与使用方法。该检查单是 发布前的架构、发布质量与事件管理就绪度自评。

**华为云对应服务**：运维就绪检查（运维就绪度（ORR））
**检查单文件**：`src/checklists/ORR-Lens.md`
**题目总数**：16 题，覆盖 3 个支柱

## 覆盖支柱

| 支柱 | 题量 |
|---|---|
| 01 - Architecture | 6 |
| 02 - Release Quality | 5 |
| 03 - Event Management | 5 |

## 评估方法

1. 逐题对照本仓架构给出**良好 / 部分符合 / 不符合**三档自评
2. 对「部分符合 / 不符合」的题目，参照检查单内的「期望回答（参考）」生成行动项
3. 行动项需明确责任域、优先级与目标日期

## 与其他检查单的关系

本检查单覆盖**运维就绪度**单一架构域。若目标架构同时涉及其他服务域（如存储、身份、消息），请配套使用对应的领域检查单，避免只评估局部而遗漏跨域依赖。

## 题目结构约定

每个检查单统一由以下部分组成：

- **评估说明**：三档自评规则
- **支柱章节**（`## <支柱>（N 题）`）：按支柱组织题目
- **题目条目**（`### <编号> <标题>`）：含「说明」「期望回答（参考）」，部分题目附带改进计划
