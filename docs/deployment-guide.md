# 使用指导书

本指导书说明如何使用 `lean-governance-custom-lens-wa` 检查单库开展架构评估。

## 1. 前置条件

- 熟悉目标架构（服务清单、访问模式、SLA 要求）
- 参与人员：架构师 / 运维 / 安全各域负责人
- 无需云资源（检查单为离线评估模板）

## 2. 使用流程

1. 按目标架构选择检查单（如对象存储架构 → `src/checklists/OBS-Lens.md`，对应 OBS）
2. 逐题自评：良好 / 部分符合 / 不符合
3. 对「不符合 / 部分符合」对照「期望回答与改进计划」生成行动项
4. 汇总行动计划（责任域 + 优先级 + 目标日期）

## 3. 行动项示例

```text
| 检查项 | 自评 | 行动 | 责任域 | 优先级 |
|---|---|---|---|---|
| DDBSEC1 安全运行 | 部分符合 | 启用服务端加密 + 最小权限 | 安全 | 高 |
```

## 4. 常用检查单速查

| 场景 | 检查单 |
|---|---|
| 键值/NoSQL | `GeminiDB-Lens.md` |
| 对象存储 | `OBS-Lens.md` |
| 无服务器 API | `APIG-FGS-Lens.md` |
| 容器 | `CCE-Lens.md` |
| 整体护照 | `Passport-Lens.md` |

## 5. 无云资源 / 清理

检查单为离线模板，无后台资源，无需清理。
